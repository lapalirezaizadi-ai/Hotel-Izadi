# 🏨 سامانه رزرواسیون و مدیریت خدمات هوشمند هتل (Smart Hotel Management)

این ریپازیتوری مربوط به پروژه پایانی درس برنامه‌نویسی مبتنی بر وب است. در این پروژه یک پرتال جامع برای مهمانان و بخش پذیرش هتل توسعه داده می‌شود که فرآیند رزرو و مدیریت خدمات اقامتی را هوشمندسازی می‌کند.

## 🎯 معرفی پروژه
هدف این سامانه، ایجاد ارتباطی یکپارچه بین مسافر و هتل از لحظه رزرو اتاق تا پایان اقامت است. مسافران می‌توانند علاوه بر رزرو آنلاین، از طریق پنل کاربری اختصاصی خود (داشبورد هوشمند اتاق) درخواست‌های خدماتی خود را ثبت و وضعیت اتاق را مدیریت کنند.

## 👥 کاربران سیستم
- **مهمانان هتل:** رزرو سریع، مشاهده صورت‌حساب، درخواست خدمات داخل اتاق (Room Service) به صورت آنلاین.
- **پذیرش و پرسنل:** مدیریت یکپارچه اتاق‌ها، بررسی وضعیت اشغال و پاسخگویی سریع به درخواست‌های مهمانان.
- **مدیریت:** دسترسی به گزارش‌ها، آمار رزروها و بازخورد مسافران.

## ✨ امکانات اصلی
1. **سیستم رزرواسیون:** جستجو، فیلتر و رزرو آنلاین اتاق‌ها.
2. **داشبورد اختصاصی مهمان:** مشاهده سوابق، صورت‌حساب لحظه‌ای و وضعیت اقامت.
3. **پرتال خدمات اتاق (Room Service):** ثبت آنلاین درخواست نظافت، سفارش از کافی‌شاپ و اعلام خرابی.
4. **پنل هوشمندسازی:** تنظیم وضعیت اتاق (مثل حالت "مزاحم نشوید" یا درخواست شارژ اقلام).
5. **داشبورد مدیریت و پذیرش:** تایید/لغو رزروها و تغییر وضعیت اتاق‌ها.

## 🛠 ابزارها و تکنولوژی‌های مورد استفاده
- **بک‌اند:** Python / Django 
- **دیتابیس:** SQLite / PostgreSQL (قابل ارتقا)
- **فرانت‌اند:** HTML, CSS, JavaScript (طراحی مینیمال و دارک با استفاده از کامپوننت‌های MDUI)
